# UKK Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Telegram bot becomes UKK, a Kekkonen-inspired statesman for newcomers to Finland, running on the production server today; the website and docs follow in a separate PR for Zachary.

**Architecture:** Persona and voice live in `hermes/SOUL.md` and the three butler skills; the local gate decides wakes (`hermes/plugins/kaveri-gate/gate.py`); Telegram's display name is set through the Bot API. The Engine is untouched. The bot branch is deployed by hand with the existing server deploy script, then merged; the site rename is a second branch from `main`.

**Tech Stack:** Hermes (pinned), Python 3 standard library (`unittest`), Ollama `gemma3:1b`, Docker Compose on the Verda server, Telegram Bot API, Next.js (Part 2 text only).

**Spec:** `docs/superpowers/specs/2026-11-14-ukk-identity-design.md`

## Global Constraints

- Name: **UKK**. Audience: **newcomers to Finland** (first year or two; work or study movers and their families; family, flatmate and cohort group chats).
- UKK never claims to be Kekkonen or a president, never quotes him, never comments on politics, the Soviet era or current government.
- No portrait or likeness anywhere.
- Humour stays in the wrapping. Plan lines, deadlines and amounts are posted exactly as the Engine returns them.
- No jokes on bad news (job loss, illness, death).
- Every existing rule in `hermes/SOUL.md` stays: evidence, approval, material-not-orders, language, privacy, one household per chat, `[SILENT]` in groups, never silent in DMs.
- Technical identifiers keep their names: `kaveri-gate`, `KAVERI_*`, `@junction_kaveri_bot`.
- "AIDaddy" and "Kaveri" keep waking the bot.
- No Engine, grounding, research, country or language changes.
- Commits: imperative subject, at most 72 characters, no model names or secrets. Decisions go in `docs/DECISIONS.md` with a Helsinki timestamp.
- Never "legal advice" or "100% accurate".

## Review Focus

1. A Finnish message that names the FAQ ("katso UKK-sivu", "UKK:sta löytyy") wakes the bot: acceptable, it is addressed by name; words that merely contain the letters ("ukko", "Ukkonen", "pukki") must not wake it. Pinned in Task 1.
2. A job-loss or illness message gets plain, warm text with no ceremony or joke. Pinned in Task 4's rehearsal.
3. The plan message keeps the Engine's lines verbatim, citation numbers included, inside UKK's wrapper. Pinned in Task 4's rehearsal.
4. A DM greeting is answered, never `[SILENT]`, and says UKK is a made-up character. Pinned in Task 4's rehearsal.
5. The group's stored memory says the old privacy note was already posted, so UKK's note (with the "made-up character" line) would never appear. Task 4 resets the test group's memory with "forget everything" before rehearsing.
